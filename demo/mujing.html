幕境 MujingAI-DRIVEN IMMERSIVE ACTIVITY ENGINE · MVP v7.2

面向线下场地（剧本杀 / 轰趴馆 / 沉浸式空间）的 AI 主理人：每一场活动从 0 生成，现场实时推进。传统剧本杀是一场固定剧本的重复演出；幕境的解法是生成层 + 运行层——先由 LLM 生成一整场活动，再由实时 harness 在现场驱动它。

TypeScript + Vite 全栈 35/35 测试通过 端到端探针 ~16 min / 场 本页为产品概述 · 可当面演示

一场活动 = 一个 ActivityPackage

生成层 · 多 pass 流水线

从骨架到长文档逐层收敛，每个 pass 有独立 prompt 与结构化契约（contracts），全程 SSE 流式可观测。

骨架与素材

pass 1–2：故事骨架、世界观与线索素材先行生成，作为后续所有 pass 的共同地基。

剧本与事件

pass 3–4.5：幕结构剧本、关键事件、高光时刻与意外事件，构建可推进的叙事引擎。

人物与关系

pass 5 系列：角色弧光、多结局、私人支线与关系网，每个角色都有独立动机。

NPC 与长文档

pass 7–15：NPC 对话人格、场景、多视角长文档与故事脊柱校验——产出即开场物料。

运行层 · 实时 harness 与四端架构

生成只是开始：现场每 90 秒一个 tick，AI 主理人根据现场信号实时决策。

实时 harness 能力

  • tick 决策循环：每 90s 评估场上状态并产出下一步动作
  • 主持人提示：实时给到场内主持的节奏与话术建议
  • 惊喜事件 / 线索推进：按策略引擎（policy）择机投放
  • NPC 召回与对话：NPC 角色随时可被唤起互动
  • 现场感知：基于 Web Speech 的语音信号接入
  • 玩家行动：质询 / 私聊 / 指认等动作全链路支持

四端交付

  • 主理人控制台 /room/:id/console — 运营视角总控
  • 大屏投放 /room/:id/screen — 现场公共画面
  • 玩家手机端 /room/:id/player — H5 角色视角
  • 复盘报告 /room/:id/report — 一场结束自动归档
  • 创建 / 预览 / 编辑器 — 活动包生成后的二次加工
  • 端到端探针 npm run probe — 真实调用验证全流程

6月18日 晴

2026-06-18 18:05 · 轰趴馆二楼储物间门口 · 页边有泪痕

早上给中班的小朋友上手工课，乐乐偷偷塞给我一朵用彩纸折的向日葵，说祝老师去山里也能每天看到太阳。我捏着那朵皱巴巴的纸花躲在教具室哭了十分钟……

下午收拾行李的时候犹豫了三次，还是把装集体照的天蓝色相册盒塞进了背包最内层……出门前收到支教队的通知，说下周一会派车来接，我对着镜子练了好几遍"我要去支教两年"的开场白，每次说到一半就卡壳。

刚才轰趴馆玄关的灯很暖，大家进门的时候都笑着抱我，我攥着背包肩带的手一直出汗，那句到了嘴边的话，还是咽回去了。
