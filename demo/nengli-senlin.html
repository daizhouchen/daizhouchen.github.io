五个核心 Flow

从首次进入到成长反馈的完整用户旅程，每一步对应真实页面与云函数。

FLOW 01

首次进入

角色选择（家长/成人）→ initUserProfile 创建档案

FLOW 02

5 维初测

5 关串联小游戏 + 草稿保存 → submitAssessment → 雷达图报告

FLOW 03

今日 3 练

generateDailyTasks 生成任务 → 训练 → 积分 / 徽章结算

FLOW 04

成长反馈

getGrowthDashboard → 雷达 + 最佳成绩 + 积分 + 徽章

FLOW 05

机构浏览

客户端直读 institutions 集合 → 详情页 → 一键拨号

工程架构与质量保障

Spec 驱动开发：PRD → 10 个 Epic → 代码，全部留档在仓库 .claude/ 目录。

小程序端（10 页面 + 4 组件）

  • 组件化：GameShell / RadarChart / TaskCard / BadgeItem 全组件复用
  • 5 维玩法：balance 稳点保持 · reaction 快速点击 · attention 干扰辨识 · coordination 拖拽归位 · stress 节奏挑战
  • 自定义 TabBar + 常量化的维度配置（颜色/文案单一数据源）

云函数端（6 个 Node.js 18.15）

  • initUserProfile · saveAssessmentDraft · submitAssessment
  • generateDailyTasks · submitTrainingResult · getGrowthDashboard
  • 全部经非交互部署脚本 deploy-fn.js 一键部署

数据与安全设计

  • 最小权限：9 个集合中仅 3 个公共集合（badges / institutions / training_templates）允许客户端直读，其余全部云函数写入
  • 幂等：训练奖励基于 rewardGranted flag 首次达标发放；每日任务当日存在直接返回
  • 种子数据：徽章 4 / 机构 4 / 训练模板 33，建集合脚本幂等可重跑

交付工程

  • 一键命令：schema 建集合 / 云函数批量部署 / miniprogram-ci 上传与预览二维码
  • E2E 冒烟：e2e-smoke.js + CI 校验脚本
  • PRD V1.2.1 审校版 1800KB 完整文档随仓库交付，含性能验收目标（冷启动 / P95）

能力森林为私有仓库项目（V1.2.1，已上传小程序版本 0.1.2）。完整源码、PRD 与部署脚本可在沟通后提供访问。
